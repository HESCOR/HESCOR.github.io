# HESCOR project website archive

This repository hosts the long-term static archive of the HESCOR (Human & Earth System Coupled Research) project website.

**Website:** https://hescor.github.io/

The archive preserves the publicly available pages, media, educational material, and interactive H5P content from the original WordPress website at [hescor-project.com](https://www.hescor-project.com/). It is served directly from the `main` branch through GitHub Pages and does not require WordPress, PHP, or a database.

## About HESCOR

HESCOR was an interdisciplinary research initiative at the University of Cologne connecting Earth system science, human-system modelling, archaeology, and the humanities to investigate interactions between nature and culture.

## Archive maintenance

The checked-in files are generated static output. The export tooling and documentation used to produce the archive are maintained separately from the deployed site files. Internal links and assets use site-root-relative paths so the archive remains independent of the original domain.
