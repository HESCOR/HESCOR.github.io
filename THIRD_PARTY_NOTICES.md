# Third-party notices

## About this repository

This repository is a static archival copy of the former HESCOR WordPress
website. It contains generated HTML and the browser-side stylesheets,
JavaScript, fonts, icons, and media required to preserve the public website.
It does not contain a working WordPress installation or the server-side PHP
source of the installed plugins.

Copyright in HESCOR-authored text, images, video, and other project material
remains with HESCOR and/or the identified authors and rights holders. All
third-party components remain subject to their own licenses. Inclusion in this
archive does not relicense a third-party component or other third-party work.

The license texts referenced below are reproduced in [`LICENSES/`](LICENSES/).
This notice is informational and is not a substitute for the license terms.
